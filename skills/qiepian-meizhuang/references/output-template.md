# 输出格式模板（阶段二确认后使用）

本文件规定阶段三四板块的标准写法。实际输出必须按用户阶段一/二的选择填充，不得照抄模板文字。

## 1. 保留清单（按原 SRT 物理顺序）

```text
【Source 1 · 文件名】
- [00:XX:XX,XXX --> 00:XX:XX,XXX] ➔ 该片段最有识别度的一句原话 ➔ [高能卖点标签]
- ...

【Source 2 · 文件名】
- ...

【Source 3 · 文件名】
- ...
```

要求：
- 严格按 Source 1 → 2 → 3 文件顺序，不打乱时间轴；
- 每行一个片段，时间戳与台词均来自原 SRT；
- 高能标签从四大指标中选择（性价比机制/极限测试/反差人设/暴力逼单），可组合；
- 跨稿件深度融合模式：在清单外附「融合结构」——各段文案分别取自哪些 Source 的哪些片段。

## 2. 修改对照表（Before vs After）

| 来源（场次+时间轴） | 原始台词（Before） | 处理后台词（After） | 优化/防封原因 |
| --- | --- | --- | --- |

- **100% 还原版**：仅处理违规词（防封替换或整段切除），口癖与复读全部保留；
- **优化精简版**：在还原版基础上，另砍语气词、无效复读，理顺口误与数字矛盾；
- 每行必须标注来源（Source + 大致时间轴），方便剪辑师回原片定位。

## 3. 文案干净稿（跨场次/单场次 60 秒）

结构（跨场次深度融合版）：
1. Hook：反差开场（炫富人设 × 便宜价格）
2. 极限测试：实测画面口播（温度/泼水/刮蹭/遮瑕）
3. 降维种草：反常识科普或贵妇对比（内幕/背书）
4. 霸气逼单：价格机制 + 无忧售后 + 稀缺收尾

结构（单稿件独立切片版）：按该场次自身高能顺序，Hook → 核心高能 → 逼单。

要求：
- 总时长约 60 秒、约 240–300 字；
- 核心产品卖点与机制（价格、件数、售后）**加粗**；
- 不出现违规词、口误、复读；
- 用户选 100% 还原版时以原话串联；选精简版时使用优化台词。

## 4. 误删审计（Risk Audit）

每条例出：片段定位（Source+时间轴+原话）→ 删除原因 → 潜在价值（引流/人设）→ 捞回策略。
