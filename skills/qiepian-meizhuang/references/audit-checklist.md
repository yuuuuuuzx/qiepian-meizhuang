# 审计清单（阶段二风险揭示、阶段三防封替换）

## 一、阶段二：风险揭示要点（按此清单逐项扫描，向用户报告）

### 1. 违规词风险（按严重度分级）
| 等级 | 类别 | 示例 | 处理建议 |
| --- | --- | --- | --- |
| 红线 | 处方药/医疗治疗推荐 | 氨甲环酸内服、打斑瓶、开药方 | 整段切除，不做替换 |
| 高危 | 医美项目类比/器械 | 英伦提升、超声刀、打熊猫针、小气泡、海菲秀 | 切除或替换为护肤机理表述 |
| 中危 | 医疗功效宣称 | 祛斑、阻断黑色素、渗透真皮层、24小时持妆承诺 | 软化：提亮/持妆体验，去绝对化 |

### 2. 口误与事实矛盾
- 价格数字混用（如 189/100/89 交替出现）
- 温度、数量等前后矛盾（如 15度 vs 35度）
- 语序断裂、残句（如“24小时，不，只要你不卸妆”）
- 错字/漏字（如“有提个替换装”）

### 3. 复读与注水
- 机制话术高频重复（数量/件数/价格反复念）
- 催单套话堆叠（“赶紧拍”“最后X单”重复）
- 语气词密集（呃、啊、那个、对不对、明白了吗）

### 4. 泛娱乐内容
- 约帅哥、男模、打碟、夜店、个人生活闲聊与卖点无关
- 处理：全删防跑粉，除非用户明确要求留作引流

## 二、阶段三：防封替换清单（写修改对照表时使用）

| 原始表达 | 替换/处理 |
| --- | --- |
| 氨甲环酸（内服/外用推荐） | 整段切除 |
| 打熊猫针/小气泡/海菲秀/超声刀/英伦提升 | 整段切除，或替换为“老废角质浮出、皮肤透嫩”类肤感表述 |
| 祛斑/淡斑 | 提亮肤色、改善暗沉 |
| 阻断黑色素/渗透真皮层 | 肤色更均匀、很多人反馈有提亮 |
| 24小时不脱妆 | 只要不卸妆就不掉（去绝对化） |
| “运某险”等谐音口误 | 运费险 |
| 价格混用（189/100/89） | 统一为实付价，机制一句话说清 |
| 医美医院/机构名称 | 删除 |
| 假药/违规渠道指控 | 删除（涉及第三方负面） |

## 三、交付前自查
1. 保留清单中是否混入红线违规段（必须为 0）；
2. 干净稿是否含违规词、绝对化承诺、口误（必须为 0）；
3. 时间戳是否全部来自原 SRT（无虚构）；
4. 用户选择的台词形态（还原/精简）是否贯穿对照表与干净稿；
5. 阶段一框架（融合/单场）是否贯穿保留清单与干净稿结构。
