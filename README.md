# qiepian-meizhuang

当用户上传美妆带货直播的 SRT 字幕文件并要求做切片方案时使用：按阶梯式三阶段互动确认（跨稿件模式→台词纯净度→成果输出）后，一次性交付带时间戳的保留清单、修改对照表、60秒文案干净稿与误删审计。仅适用于美妆带货直播字幕切片；不处理非美妆直播、视频剪辑本身或无需字幕的素材。

## 安装

```bash
npx -y skills add yuuuuuuzx/qiepian-meizhuang -g --all
```

## 使用

安装后，可以这样开始：

> 使用 $qiepian-meizhuang 为我的美妆带货直播 SRT 稿件做切片方案

上传 1 份或多份美妆直播 SRT 字幕文件后，技能会先与你确认剪辑框架（跨稿件深度融合审计 / 单稿件独立切片）与台词形态（100% 还原原稿 / 优化精简台词），再一次性输出：带时间戳保留清单、修改对照表、60 秒文案干净稿、误删审计。

## 运行依赖

- 支持 Agent Skills 的客户端
